# Trel v0.6.0

**New:**
- Command palette on Ctrl+K: sections, versions, worlds, servers, and actions from a single search
- Catalog of mods, shaders, and packs from Modrinth — install into the selected version in one click
- Instances: separate game folders with their own versions, mods, worlds, memory, and Java
- Performance presets are picked per Java version, memory is calculated automatically, and the launch command can be reviewed before starting
- Per-world statistics: time played, distance travelled, mining, kills, and achievements
- World audit: what takes up the space and a safe cleanup of junk files
- Bedrock on Linux and macOS: install and launch on an external Android device over ADB

**Fixed and improved:**
- Legacy versions (Cave Game and the early alphas) now get the preset flags, just like regular ones
- Diagnostics no longer require TrelEmu when an external Android device is connected
